# Exercícios de Java — Programação Modular

Repositório com exercícios de Java resolvidos durante o **Laboratório de Programação Modular**.

## 📂 Organização

Os exercícios estão separados por tema/tópico estudado, em ordem crescente de complexidade:

| Pasta | Conteúdo |
|---|---|
| `01-fundamentos` | Entrada e saída de dados, revisão de estruturas básicas |
| `02-classes-e-objetos` | Definição de classes, atributos, métodos e objetos |
| `03-strings-e-datas` | Manipulação de texto e datas |
| `04-arquivos` | Leitura e escrita de arquivos |
| `05-colecoes` | `List`, `Map`, `Set` e demais coleções |
| `06-heranca` | Herança entre classes |
| `07-polimorfismo-e-interfaces` | Polimorfismo e uso de interfaces |
| `08-tratamento-de-excecao` | Tratamento de erros com `try`/`catch` |
| `09-testes-unitarios` | Testes unitários com JUnit |
| `10-programacao-generica` | Generics em Java |

## 🛠️ Tecnologias

- Java 17+

## ▶️ Como executar

Cada exercício é um arquivo `.java` independente. Para rodar:

```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```
